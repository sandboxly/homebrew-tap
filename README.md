# sandboxly/homebrew-tap

Homebrew casks for the Orchard apps:
[Orchard Commander](https://sandboxly.github.io/orchard-commander/),
[Orchard Music Player](https://sandboxly.github.io/orchard-music-player/) and
[Orchard Download Manager](https://sandboxly.github.io/orchard-download-manager/).

```sh
brew install --cask sandboxly/tap/orchard-commander
brew install --cask sandboxly/tap/orchard-music-player
brew install --cask sandboxly/tap/orchard-download-manager
```
