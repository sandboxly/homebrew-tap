# sandboxly/homebrew-tap

Homebrew casks for the Orchard apps:
[Orchard Commander](https://sandboxly.github.io/orchard-commander/) and
[Orchard Music Player](https://sandboxly.github.io/orchard-music-player/).

```sh
brew install --cask sandboxly/tap/orchard-commander
brew install --cask sandboxly/tap/orchard-music-player
```
